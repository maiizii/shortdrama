# 2026-09-18 双项目同步记录

维护目录为 `短剧库/` 与同级 `果果剧库/`。本次将当天的通用修复和两轮红果搜索更新按功能合并到果果剧库；专用版保持“果果剧库”名称、8999 默认端口与红果来源 / ID 校验。两边根目录的 `AGENTS.md` 已明确这两个实际路径，旧的 `juku/` 不再作为同步目标。

## 同步成果

- 红果搜索增加输入联想、名称索引补全、标题归一化与相关度排序，保留不同季，并提示分类隐藏的结果。
- 播放增加有界前向缓存、暂停填充、配额恢复与切集预缓存接管，修复 HLS 重定向后的分片地址和不完整输出回退。
- 混合 HE-AAC 音轨可统一为 AAC-LC，兼容视频保持复制，失败保留已完成进度。
- Emby 自动补入合并全集特别篇 STRM / NFO，支持签名本地播放及 Range / HEAD，并保存本地海报。
- 按站源保存默认关闭，新剧进入来源目录，已有下载与 Emby 目录继续复用；果果版只使用红果目录。
- 登记封面的 Fake-IP 解析可通过备用 DNS 恢复，仍校验和固定连接公网地址。

果果版只增加名称归一化所需的 `golang.org/x/text`，Go 最低版本更新为 1.24.1，Docker 构建包含 `go.sum`。专用版没有引入其他站源、其登录入口或 TLS 指纹依赖。同步文件仅包含源码、静态资源、构建文件、说明与 `dist/` 成品；不迁移两边的配置、账号、缓存、任务、下载或便携 FFmpeg。
