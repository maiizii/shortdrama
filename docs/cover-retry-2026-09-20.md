# 海报点击重试

海报加载失败后，原页面只能等待资料刷新完成再尝试恢复。资料请求执行中或处于五分钟冷却时，再次点击播放不会重试；重复使用同一个失败地址也可能复用浏览器中的失败状态。

本次将失败海报重试与资料刷新冷却分开。每次明确点击播放或打开详情，剧库、详情及追剧会立即重试当前剧集已经失败的海报。资料刷新保持请求共享和原有冷却，不阻塞播放。海报地址变化时正常更新，普通读取或页面重载不自动补齐历史资料。

重试标记仅加入本地 `/api/ui/image` 请求，源站完整签名地址和剧库记录不变。账号、剧集 ID、红果单来源、图床登记和 DNS 校验继续生效。专用版未加入其他站源的解码器、图床、配置或入口，各自运行数据没有同步或覆盖。

验证使用虚构文字数据，未请求、下载、查看或处理站源图片：

- 相关 Go race 回归及红果单来源检查通过。
- 49 项 JavaScript 测试通过，包含请求共享、资料冷却期间仍触发海报重试、地址签名保留。
- Chrome 使用实际页面模块，验证连续播放、请求执行中和冷却期间重试、详情重开及播放、追剧播放；全程一次资料刷新、零次额外补齐请求，无关条目不被重试。
- 浏览器在发送前中止全部图片请求，本地页面和接口只返回文字夹具，其他请求均拒绝，没有截图，也未进行真实海报显示验证。

安装 Playwright 后运行 `node scripts/check-cover-retry.cjs` 可复查页面流程；`PLAYWRIGHT_MODULE` 和 `JUKU_BROWSER_EXECUTABLE` 可指定现有模块与浏览器。相关代码由 Go 嵌入，两版分别重新构建四个平台程序和对应 ZIP。

关闭旧程序后启动新的 `dist/` 程序，再刷新网页并点击播放或详情重试。使用源码时重新启动 `go run .`。保留 `data/`、账号、观看记录、下载和 FFmpeg，无需清库。
